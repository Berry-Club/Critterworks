# Data Packs

Critterworks exposes tags that allow data packs and other mods to extend its gameplay, world generation, and spawning.

## Travel Surfaces

Add blocks to `critterworks:supports_scoochworm_travel` to let Scoochworms travel across them.

Ordinary tagged blocks support travel on all six faces. Some special blocks, like the [Scoochstem](@critterworks:scoochstem), can disable travel on specific faces.

Add blocks to `critterworks:prevents_scoochworm_wandering` to stop freely wandering Scoochworms from crawling across their faces. This does not affect routed travel provided through `critterworks:supports_scoochworm_travel`.

## Saddles

Add items to `critterworks:scoochworm_saddles` to let players equip them as saddle attachments. Vanilla [Saddles](@minecraft:saddle) are included by default.

## Critter Cages and Snail Shields

Add entity types to `c:capturing_not_supported` to prevent [Critter Cages](@critterworks:critter_cage) from capturing them. Scoochworm parts are included by default.

Add entity types to `critterworks:can_target_fully_shelled_players` if they should continue targeting players who have been motionless inside a [Snail Shield](@critterworks:snail_shield) for five seconds.

## World Generation and Spawning

The following tags control where Critterworks content generates or spawns:

| Tag | Content |
| --- | --- |
| `critterworks:has_filterfeeder` | Filterfeeders |
| `critterworks:has_sproutsnail` | Sproutsnails |
| `critterworks:has_scoochworm_apple` | Scoochworm Apples |
| `critterworks:has_hopping_spider_nest` | Hopping Spider Nests |
| `critterworks:has_sparkbug_bush` | Sparkbug Bushes |
| `critterworks:has_scoochstem_vine` | Scoochstem vines |

These are biome tags. `critterworks:has_punchprawn` is a structure tag that controls where Punchprawns spawn.
