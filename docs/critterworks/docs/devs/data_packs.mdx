# Data Packs

Critterworks exposes tags that allow data packs and other mods to extend basic Scoochworm behavior.

## Travel Surfaces

Add blocks to `critterworks:supports_scoochworm_travel` to let Scoochworms travel across them.

Ordinary tagged blocks support travel on all six faces. Some special blocks, like the [Scoochstem](@critterworks:scoochstem), can disable travel on specific faces.

Add blocks to `critterworks:prevents_scoochworm_wandering` to stop freely wandering Scoochworms from crawling across their faces. This does not affect routed travel provided through `critterworks:supports_scoochworm_travel`.

## Saddles

Add items to `critterworks:scoochworm_saddles` to let players equip them as saddle attachments. Vanilla [Saddles](@minecraft:saddle) are included by default.
