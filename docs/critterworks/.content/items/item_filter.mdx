The **Item Filter** controls which items can pass through a [Web Port](@critterworks:web_port).

Use the filter in your hand to open it. Place example items into its 16 ghost slots; configuring the filter does not consume those items. Insert the configured filter into a Web Port to apply it.

## Options

| Option | Result |
| --- | --- |
| Inverted | Allows everything except the listed items. |
| Use Tags | Also matches items that share a tag with a listed item. |
| Ignore Damage | Matches damaged and undamaged versions of the same item. |
| Ignore All Components | Matches the item type without checking any extra item data. |

Item Filters can be placed inside other Item Filters when a setup needs a reusable group of rules.
