**Web Lines** form the routes in a [Web Network](@critterworks:web_networks). Any connected group of lines belongs to the same network.

## Creating Lines

Use **Artificial Spinnerets** on a block face to select the first endpoint, then use them on another block face to create a line between the two. You can also select a point on an existing line to create a branch. The Spinnerets glint while the first point is selected; sneak and use them in the air to cancel.

Artificial Spinnerets hold up to 128 blocks' worth of Web Fluid. In an inventory, pick up String and place it onto the Spinnerets to refill them; each String restores enough fluid for one block of line. Creative-mode players do not consume Web Fluid.

A line must be shorter than 10 blocks, have a clear path between its endpoints, and use block faces that point in different directions. Longer lines consume more Web Fluid.

Use **Shears** on a Web Line to remove it. Any other Web Lines that depended on it will also be lost.

## Finding Routes

Use a **Web Pathfinder** on one point in the network, then use it on another point. If the two points are connected, the shortest route between them is briefly highlighted.

The Web Pathfinder also glints after its first point is selected. Sneak and use it in the air to clear the selection.
