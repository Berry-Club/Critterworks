**The Snail That Kills You** is the ghost of a [Sproutsnail](@critterworks:sproutsnail), endlessly chasing down the player that slew it. This has a 1% chance of happening by default. Only one can pursue a player at a time.

The Snail moves directly towards its target, passing through blocks. It stops moving only when the target is offline or in another dimension. The Snail That Kills You kills you if it reaches you.

A [Critter Cage](@critterworks:critter_cage) may be used to buy yourself time, but only a [Snail Shield](@critterworks:snail_shield) will end the chase permanently. Letting it reach you while protected by a Snail Shield will teleport the Snail away. Repeating this process 5 times will instead banish the Snail, ending the chase forever.

## Commands

Operators can manage a pursuit with `/critterworks snail-chase`:

| Command | Result |
| --- | --- |
| `/critterworks snail-chase info [player]` | Reports the snail's position, dimension, and distance. |
| `/critterworks snail-chase start [player] [position]` | Starts a pursuit, optionally at a chosen position. |
| `/critterworks snail-chase end [player]` | Ends the pursuit. |

When omitted, the player argument defaults to the operator running the command. A default starting position is ten blocks east of the target player.
