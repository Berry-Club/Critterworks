The **Web Pathfinder** is a debugging tool that highlights the shortest route between two connected points in a [Web Network]($players/web_networks).

Use the Web Pathfinder on one point in the network, then use it on another point. If the two points are connected, the shortest route between them is briefly highlighted.

Sneak and use it in the air to clear the selection.
