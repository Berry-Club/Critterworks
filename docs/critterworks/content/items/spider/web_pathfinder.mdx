The **Web Pathfinder** highlights the shortest route between two connected points in a [Web Network](@critterworks:web_networks).

Use the Web Pathfinder on one point in the network, then use it on another point. If the two points are connected, the shortest route between them is briefly highlighted.

The Web Pathfinder glints after its first point is selected. Sneak and use it in the air to clear the selection.
