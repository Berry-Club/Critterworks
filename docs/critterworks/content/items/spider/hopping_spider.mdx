**Hopping Spiders** carry items between inventories connected to a [Web Network]($players/web_networks).

Add a Hopping Spider to a [Hopping Spider Nest](@critterworks:hopping_spider_nest) by using the item on the nest. The spider then travels along [Web Lines](@critterworks:artificial_spinnerets), moving items from input [Web Ports](@critterworks:web_port) to compatible output ports before returning home.

Hopping Spiders are found in naturally generated nests. Breaking a nest or sneak-interacting with it using an empty hand returns its spiders as items. A name applied with an Anvil is preserved when the spider enters or leaves a nest.

A Hopping Spider can also be equipped in the head slot and worn as a hat.
