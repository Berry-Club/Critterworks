The **Fluid Filterfeeder** controls which fluids are accepted by certain things.

Use the item in your hand to open it. Place example fluid-containing items (like Buckets) into its 16 ghost slots; configuring the filter does not consume those items.

Throwing the Filterfeeder into water will convert it back into [its mob form](@critterworks:filterfeeders).

## Options

| Option | Result |
| --- | --- |
| Inverted | Allows everything except the listed items. |
| Use Tags | Also matches items that share a tag with a listed item. |
| Ignore All Components | Matches the item type without checking any extra item data. |

Fluid Filterfeeders can be placed inside other Fluid Filterfeeders to nest them, if you need more than 16 filter entries.
