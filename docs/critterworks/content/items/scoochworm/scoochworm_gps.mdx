The **Scoochworm GPS** is a chunk loading attachment for [Scoochworms](@critterworks:scoochworm).

The attachment keeps five chunks loaded: the chunk containing the Scoochworm's head and the four chunks directly north, south, east, and west. The loaded area follows the Scoochworm as it moves.

Only one GPS can be attached to a Scoochworm. Sneak and interact with its segment using an empty hand to remove it and stop loading the surrounding chunks.

The Scoochworm GPS item is not actually consumed when attaching it to a Scoochworm. This is because chunk loading is more of an engine limitation, rather than an intentional game mechanic.

## Configuration

Each player can own up to 15 active Scoochworm GPS attachments by default. Server owners can configure this limit.
