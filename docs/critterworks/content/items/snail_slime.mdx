Adult [Sproutsnails](@critterworks:sproutsnail) passively drop **Snail Slime** every five to ten minutes.

It can be used the same way as Bone Meal.

Using it on a block while sneaking will cover it with Snail Slime, which functions similarly to [Honey Blocks](https://minecraft.wiki/w/Honey_Block), allowing you to slowly slide down the side of blocks.
