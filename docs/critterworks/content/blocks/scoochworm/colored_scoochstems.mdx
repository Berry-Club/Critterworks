Colored Scoochstems create color-specific routes for [Scoochworms](@critterworks:scoochworm).

A Scoochworm can travel on a Colored Scoochstem only when their [Dyeberry](@dyeberries) colors match.

Ordinary [Scoochstem](@critterworks:scoochstem) accepts every color, so it can be used for shared sections of a route. Add Colored Scoochstems where the route needs to split.

Keep in mind that Scoochworms prefer to turn horizontally instead of vertically. A path that forks by either turning left onto a Blue Scoochstem or "upward" onto a regular Scoochstem wall, blue Scoochworms will turn left, and other Scoochworms will crawl up onto the wall.

Unlike ordinary Scoochstem, individual faces cannot be disabled with an axe.

Make sure each color has a valid continuation: a Scoochworm stops if none of the available stems match its color.
