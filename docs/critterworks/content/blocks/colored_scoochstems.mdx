Colored Scoochstems create color-specific routes for [Scoochworms](@critterworks:scoochworms).

Colored Scoochstems are available in six colors:

- Green
- Blue
- Red
- Yellow
- Magenta
- Cyan

## Routing

A Scoochworm can travel on a Colored Scoochstem only when their colors match.

Ordinary [Scoochstem](@critterworks:scoochstem) accepts every color, so it can be used for shared sections of a route. Add Colored Scoochstems where the route needs to split.

For example, a junction with a Red Scoochstem on one branch and a Blue Scoochstem on another sends red Scoochworms onto the red branch and blue Scoochworms onto the blue branch. Other colors cannot use either colored branch.

## Changing a Scoochworm's Color

Use a [Dyeberry](@critterworks:dyeberries) on any part of a Scoochworm to change its color. The berry is consumed unless the Scoochworm is already that color. Splitting a Scoochworm with shears gives both resulting Scoochworms the original color.

## Building Routes

Colored Scoochstems support travel on every face, allowing matching Scoochworms to move across floors, walls, and ceilings. Unlike ordinary Scoochstem, individual faces cannot be disabled with an axe.

Make sure each color has a valid continuation: a Scoochworm stops if none of the available stems match its color.
